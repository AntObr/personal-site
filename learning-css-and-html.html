I know just enough HTML and CSS to get by, but I've never built a real understanding of how it works and how I need to think to make things look the way they do in my head.

So to learn more about HTML and CSS I want to build my own simple CSS theme that I can use across this website. For this I want to explore HTML's semantic elements described by MDN here so that once done I can build out full pages by writing purely semantic HTML with little to no additional CSS required.

Goals

  • Explore the range of semantic HTML elements
  • Ensure the HTML and CSS are built responsively

Semantic HTML

pre

<pre> represents preformatted text and have niche uses outside of specific cases. This element is only mentioned to provide context for where it is used later.

code

<code> represents a short fragment of computer code and generally represents a single line of text.

As this represents a single line of code to represent multiple lines it should be wrapped in <pre>.

<pre>
    <code>
function calcRectArea(width, height) {
  return width * height;
}

console.log(calcRectArea(5, 6));
// Expected output: 30
    </code>
</pre>

Result

function calcRectArea(width, height) {
  return width * height;
}

console.log(calcRectArea(5, 6));
// Expected output: 30

span

<span> is a generic inline container for text content that doesn't inherently represent anything.

<span>some text</span>

Some classes for use with span for styling text are available below.

highlight

<p><span class="highlight">some text</span>

Result

some text
